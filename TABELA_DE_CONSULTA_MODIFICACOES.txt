================================================================================
          TABELA DE CONSULTA RÁPIDA: COMO MODIFICAR O CÓDIGO
     Guia Prático Para Quem Nunca Programou na Vida — Oficina ESP32 (SNCT)
================================================================================

Este guia foi feito especialmente para você que nunca mexeu com programação.
Se você precisa mudar a sua rede Wi-Fi, trocar um sensor de pino, mudar o tempo
de envio ou alterar textos, basta consultar a tabela abaixo.

--------------------------------------------------------------------------------
⚠️ REGRAS DE OURO (LEIA ANTES DE MUDAR QUALQUER COISA):
--------------------------------------------------------------------------------
1. NUNCA apague as aspas duplas (" "). O texto sempre deve ficar dentro delas.
   Exemplo CERTO:   const char* SSID = "MinhaRede";
   Exemplo ERRADO:  const char* SSID = MinhaRede;

2. NUNCA apague o ponto e vírgula (;) no final da linha. Ele avisa que a ordem acabou.
   Exemplo CERTO:   #define DHTPIN 5
   Exemplo CERTO:   int led = 26;
   Exemplo ERRADO:  int led = 26

3. MAIÚSCULAS e MINÚSCULAS importam! Se o código tem "WiFi", não escreva "wifi".

================================================================================
GUIA RÁPIDO: QUAIS FIOS LIGAR NO ESP32 E NO SENSOR DHT22?
================================================================================

O sensor DHT22 possui 3 pinos (na placa com plaquinha vermelha/azul) ou 4 pinos:

    PINO DO SENSOR           | ONDE LIGAR NO ESP32
    -------------------------+-----------------------------------------
    VCC ou + (Alimentação)   | Pino 3V3 (ou VIN/5V dependendo do módulo)
    GND ou - (Terra)         | Pino GND (Qualquer pino GND do ESP32)
    DAT ou OUT ou S (Dados)  | Pino D5 (GPIO 5)

DICA PARA O LED:
    - Perna Maior do LED (+)  -> Resistor de 220 ou 330 Ohms -> Pino D26 (GPIO 26)
    - Perna Menor do LED (-)  -> Pino GND do ESP32


================================================================================
RESOLUÇÃO DE PROBLEMAS MAIS COMUNS (QUANDO ALGO DÁ ERRADO):
================================================================================

1. O Wi-Fi fica mostrando apenas pontinhos (".....") e não conecta:
   -> Verifique se a sua rede é de 2.4 GHz. O ESP32 NÃO funciona no Wi-Fi de 5 GHz!
   -> Verifique se o nome da rede e a senha foram digitados exatamente iguais.

2. Mensagem "Falha ao ler o sensor DHT!":
   -> O fio de dados está folgado no pino D5 ou o sensor está sem alimentação (3V3/GND).
   -> Verifique se o pino no código (#define DHTPIN 5) é o mesmo onde você conectou o fio.

3. O Arduino IDE não encontra a porta serial (COM):
   -> Verifique se o cabo USB é de DADOS e não apenas cabo de carregar celular.
   -> Instale o driver do chip USB da sua placa (Driver CH340 ou CP2102).

4. O upload para o ESP32 trava em "Connecting........_____.....":
   -> Quando aparecer "Connecting...", segure o botão "BOOT" da placa ESP32 por 2 segundos
      até a barra de progresso começar a subir e depois solte.
